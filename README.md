# COVID-19 Information Website

## Project Description
This is a Software Testing and Quality Assurance mini project. It is a dynamic website that provides COVID-19 information and allows users to register, log in, and submit comments.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Features
- COVID-19 information homepage
- User registration and login
- User dashboard
- Comment submission
- Input validation using Regular Expressions
- Software testing test cases and test report

## Project Structure
- `index.html` – Homepage
- `style.css` – Website design
- `script.js` – JavaScript validation
- `db.php` – Database connection
- `register.php` – User registration
- `login.php` – User login
- `dashboard.php` – User dashboard
- `comment.php` – Comment submission
- `logout.php` – Logout functionality
- `testing/` – Test cases and test report

## How to Run
1. Install XAMPP.
2. Start Apache and MySQL.
3. Create the required database and tables in phpMyAdmin.
4. Place the project folder inside the XAMPP `htdocs` directory.
5. Open `http://localhost/covid19_project/` in your browser.

## Testing
The project includes functional testing and Regular Expression (Regex) test cases for input validation.
